# Phase 9 통합 운영 대시보드

## 제공 지표

- 전체·활성 상품 수
- 전체·활성 회원 수
- 전체 주문 수와 주문 상태별 분포
- 환불 주문을 제외한 순매출
- 가용·예약 재고 합계
- 가용 수량 5개 이하인 부족 재고 상품 수
- RabbitMQ 발행 대기 Outbox 이벤트 수

화면은 로그인 후 첫 번째 `대시보드` 탭이며 30초마다 자동 갱신된다. 주문 상태 분포는 Recharts 원형 차트로 표시한다.

## 데이터 소유권

C#은 `commerce_operations`에서 상품·회원 지표만 집계한다. Java는 `commerce_order_engine`에서 주문·매출·재고·Outbox 지표를 집계한다. C#의 `GET /api/dashboard`가 Java `GET /internal/dashboard`를 내부 API 키로 호출해 결과를 합치며 다른 서비스 데이터베이스를 직접 조회하지 않는다.

순매출은 현재 상태가 `PAID`, `SHIPPED`, `COMPLETED`인 주문 금액의 합이다. 취소·환불 주문은 제외한다. 이번 단계는 운영 현황 조회이며 별도 집계 테이블이나 외부 분석 서비스는 사용하지 않는다.
