# Phase 11 운영자 감사 로그

## 기록 대상

인증된 운영자가 `/api`에서 실행한 `POST`, `PUT`, `PATCH`, `DELETE` 요청을 C# Operations API가 자동 기록한다. 상품, 회원, 재고, 주문, 결제, 환불, 배송과 정산 재집계가 포함된다. 로그인 요청은 기록 대상에서 제외한다.

기록 항목:

- 운영자 ID와 이메일
- HTTP 메서드와 요청 경로
- 자원 유형
- 응답 상태 코드와 처리시간
- 접속 IP와 User-Agent
- 서버 기록 시각

비밀번호, JWT, 내부 API 키와 요청·응답 본문은 저장하지 않는다. 감사 기록 저장 실패는 이미 완료된 업무 요청을 되돌리지 않으며 서버 로그에 오류를 남긴다.

## 조회

React `감사 로그` 탭과 `GET /api/audit-logs`에서 기간, 자원, 성공·실패 결과, 페이지 크기로 조회한다. 조회 API는 `ADMIN` 권한이 필요하다. 조회 자체는 변경 작업이 아니므로 감사 로그를 추가 생성하지 않는다.

명시적 SQL 마이그레이션 `V005__audit_logs.sql`이 `commerce_operations.audit_logs`를 생성한다.
